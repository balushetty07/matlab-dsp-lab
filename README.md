# MATLAB DSP Lab 📡

This repository contains my MATLAB programs and experiments for learning **Digital Signal Processing (DSP)** as part of my Electronics and Communication Engineering (ECE) studies.

## 📚 Contents

- **Basic Signal Processing:** Introduction to MATLAB programming and basic signal operations.
- **Week 1 – Nyquist Sampling Theorem:** Understanding the basics of sampling and the Nyquist condition.
- **Week 2 – DTFT and DFT:** Implementations of DTFT, DFT, IDTFT, and IDFT using built-in functions and manual calculations.
- **Week 3 - DFT Properties:** Implementation of DFT Properties such as Linearity, Periodicity, Circular shift, Conjugate symmetry, Circular symmetry of a sequence using built-in functions and manual calculations.

- MATLAB

- GitHub

## 🎯 Purpose

The purpose of this repository is to practise MATLAB, understand DSP concepts through practical experiments, and track my learning progress throughout the semester.
